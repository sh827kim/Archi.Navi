# 체크리스트 문서 목록

`docs/checklists` 디렉토리는 구현 진행 체크, 검증 체크, 이행 확인처럼
SPEC 본문을 보조하는 운영성 문서를 관리한다.

## 규칙
1. 기능 요구사항과 수용 기준은 `docs/spec/*-spec.md`에 둔다.
2. 구현/검증 체크리스트는 `docs/checklists/*-checklist.md`에 둔다.
3. 체크리스트 문서는 상위 SPEC 링크를 반드시 포함한다.
