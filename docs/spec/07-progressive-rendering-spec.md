# Progressive Rendering SPEC (Roadmap 3-3)

- 작성일: 2026-03-02
- 상태: Implemented
- 대상: `apps/web/src/components/mapping/rollup-graph.tsx`
- 연계 문서: `../design/05-rollup-and-graph.md`

## 1. 목적
대규모 그래프(수천 엣지)에서 초기 렌더 블로킹을 줄여 사용자 체감 응답성을 개선한다.

## 2. 범위
1. 대규모 그래프에서 점진 렌더링 모드 자동 활성화
2. 배치 단위 엣지 렌더링
3. 진행률 표시
4. 소규모 그래프 기존 즉시 렌더링 유지

## 3. 기능 요구사항
1. 활성화 조건
- 엣지 수 `>= 2000`

2. 배치 전략
- 배치 크기: `200 edges`
- 스케줄링: `requestAnimationFrame`

3. 상태 표시
- `edge rendered / total` 형태로 진행률 표기
- 렌더 완료 시 진행 상태 UI 제거

## 4. 비기능 요구사항
1. 메인 스레드 장시간 점유를 피한다.
2. 렌더 중 상호작용(패널 닫기, 레벨 전환)이 가능해야 한다.
3. 메모리 증가가 선형 범위를 벗어나지 않아야 한다.

## 5. 수용 기준
1. 2000+ 엣지에서 점진 렌더링이 자동 활성화된다.
2. 소규모 그래프는 기존 즉시 렌더링 경로를 유지한다.
3. 진행률이 배치 단위로 증가하고 최종 완료된다.
