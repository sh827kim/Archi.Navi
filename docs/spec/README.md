# SPEC 문서 목록

`docs/spec` 디렉토리는 기능별 상세 구현 SPEC을 별도로 관리한다.

## 규칙
1. 기능 SPEC 문서명은 `*-spec.md`를 사용한다.
2. SPEC 구현 체크리스트는 `*-spec-checklist.md`를 사용한다.
3. Design 설명은 중복 작성하지 않고 `docs/design` 링크로 연결한다.
